## 5 Linux commands I used today

1. **`ls`** lists the files and folders in the current working directory.
   Example: `ls`

2. **`cd`** changes the directory (moves me into another folder).
   Example: `cd folder1`, and `cd ..` goes back up one level.

3. **`cat`** reads and prints the information inside a file.
   Example: `cat notes.txt`

4. **`file`** tells me what type a file is, by looking at its content
   and not just its name. A file called `photo.jpg` could actually be
   something else, and `file` shows the truth.
   Example: `file notes.txt` might say "ASCII text"

5. **`find`** searches for files and folders.
   Example: `find . -name filename` (the `.` means "start looking in
   the current folder", and `-name` means "match this file name")

## Why Linux skills matter for security
Linux runs most of the world's servers, and many security tools are built
for it. Knowing Linux helps me understand how systems really work, so I
can use technology safely, keep my data and money protected, and defend
against attacks. If I can read logs, find files and check permissions, I
can spot when something is wrong, which is exactly what a SOC analyst or
a defender does.
