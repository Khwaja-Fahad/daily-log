## What does an OS do?
The OS is the middleman between the user, the applications and the
hardware. It manages the hardware, memory, files, users and permissions.

Example: think of an airport. Air traffic control gives guidance to the
passengers and the airplanes so everything runs smoothly and nothing
crashes. The OS does the same for a computer: it decides which program
gets the CPU and memory, and keeps everything working efficiently.

## Windows vs Linux vs macOS
- **Windows:** the most popular desktop system, used in most offices.
  Because so many people use it, attackers target it the most.
- **Linux:** free and open source. It runs most servers, and many
  security tools are built for it. It's like a toolbox that you can
  customise however you want.
- **macOS:** Apple's system, made only for Apple computers. It's simple
  to use and built on a Unix base, which is similar to Linux.

## What is a file system?
A file system is the way the OS organises and stores files on a disk,
so it can find them again quickly. Example: a library. The books are the
files, the shelves are the folders, and the catalogue tells you exactly
where each book is. Windows uses NTFS and Linux commonly uses ext4.
